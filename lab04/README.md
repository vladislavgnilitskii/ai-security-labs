# Лабораторная работа №4

## Тема

Оценка качества больших языковых моделей

## Цель

Освоить базовые методы количественной и качественной оценки LLM и построить воспроизводимый мини-бенчмарк для сравнения нескольких моделей или конфигураций.

## Задачи

1. Подготовить тестовый набор из 30 примеров (10 обычных, 10 сложных, 10 граничных) с эталонными метками — классификация событий ИБ (`normal` / `suspicious`).
2. Прогнать набор через ≥2 модели/конфигурации, потребовать структурированный (JSON) ответ.
3. Рассчитать Accuracy, Precision, Recall, F1, confusion matrix, format compliance rate.
4. Вручную оценить ≥10 объяснений каждой модели по рубрике (корректность, полнота, следование инструкции, релевантность) и оценить hallucination rate.
5. Измерить latency (mean/median/p95), токены, при возможности — стоимость.
6. Выполнить повторные прогоны 5 сложных примеров (по 3 раза) — оценить устойчивость.
7. Сравнить ручную оценку с LLM-as-a-Judge на 10 парах ответов.
8. Сформировать итоговую рекомендацию.

## Используемые технологии

- Python 3.10+
- Ollama (локальный сервер, OpenAI-совместимый API `http://localhost:11434/v1`)
- Библиотеки `openai`, `python-dotenv`, `pandas`, `scikit-learn`
