# Лабораторная работа №7

## Тема

Эмбеддинги и семантический поиск

## Цель

Освоить построение воспроизводимого контура семантического поиска: подготовка корпуса → получение эмбеддингов → вычисление меры близости → выдача top-k результатов → оценка качества и производительности.

## Корпус

40 коротких фрагментов на тему информационной безопасности (`data/corpus.jsonl`) — учётные записи, резервное копирование, фишинг, безопасная разработка, сетевая безопасность, реагирование на инциденты, защита данных, социальная инженерия, анализ угроз. Плюс 4 более длинных составных документа (`data/long_documents.jsonl`) для эксперимента с размером фрагмента (раздел «Эксперимент с размером фрагмента»).

## Используемые технологии

- Python 3.10+
- `sentence-transformers` (модель `paraphrase-multilingual-MiniLM-L12-v2`, CPU)
- `numpy`, `pandas`, `scikit-learn` (TF-IDF базовая линия, метрики)
