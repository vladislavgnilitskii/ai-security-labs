# Лабораторная работа №1

## Тема

Первое знакомство с большими языковыми моделями через API

## Цель

Освоить базовый программный цикл взаимодействия с LLM и научиться сравнивать несколько моделей на одинаковом наборе заданий.

## Задачи

1. Подключиться к API минимум двух LLM (Python-клиент).
2. Подготовить единый набор из 10+ запросов разных типов (объяснение, классификация, суммаризация, извлечение данных, код, отладка, аналитика, ИБ, деловой текст, формат).
3. Прогнать набор через каждую модель, измерить задержку, сохранить ответы и ошибки в CSV/JSON.
4. Оценить каждый ответ по критериям: корректность, полнота, следование инструкции, практическая полезность (0–2 балла).
5. Сделать сравнительный вывод о применимости каждой модели.

## Используемые технологии

- Python 3.10+
- Ollama (локальный сервер, OpenAI-совместимый API `http://localhost:11434/v1`)
- Библиотека `openai`, `python-dotenv`

Модели: указать точные идентификаторы (`ollama list`) и дату эксперимента после запуска.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # заполнить LLM_MODEL реальным именем модели
ollama serve            # если сервер ещё не запущен
ollama pull <model>      # скачать нужные модели
python src/main.py
```
