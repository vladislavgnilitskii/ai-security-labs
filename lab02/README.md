# Лабораторная работа №2

## Тема

Параметры генерации и конфигурация больших языковых моделей

## Цель

Научиться управлять поведением LLM с помощью параметров генерации и системных инструкций, экспериментально выбирать конфигурацию модели под конкретную прикладную задачу.

## Задачи

1. Исследовать влияние `system prompt` (3 варианта) на одном пользовательском запросе.
2. Исследовать влияние `temperature` (0, 0.3, 0.7, 1.0), по 5 повторов каждое значение — оценить вариативность и стабильность.
3. Исследовать влияние ограничения длины ответа (`max_tokens`) — малый/средний/большой лимит.
4. Выбрать один прикладной сценарий и сформировать для него обоснованную итоговую конфигурацию (system prompt, sampling-параметры, лимит длины, формат ответа).
5. Зафиксировать неподдерживаемые параметры API, если такие обнаружены.

## Используемые технологии

- Python 3.10+
- Ollama (локальный сервер, OpenAI-совместимый API `http://localhost:11434/v1`)
- Библиотека `openai`, `python-dotenv`

Модели: указать точный идентификатор и дату эксперимента после запуска.
